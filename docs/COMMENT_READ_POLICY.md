# 歌曲留言閱讀政策

`SongCommentReader` 是歌詞 HTML 與合輯兩種 SongDetail JSON 路由的共用讀取入口。
私密留言僅限有效 Users.Id 對應的留言者、該首歌曲 AddedByUserId，或
資料庫 Users.Manager 明確授權的管理員；名稱、前端欄位、特殊數字 ID
均不構成閱讀權。未授權留言整筆不回傳，回覆僅附加到可閱讀的同首歌曲留言。
既有新增留言與管理員回覆的寫入規則不變。

現有留言以 UserEmail 關聯 Users，讀取時解析成 Users.Id 再比較；沒有帳號
對應的舊留言不憑 Email 字串放行。沒有修改歷史留言、歌曲或帳號資料。
目前程式可證實的正式管理權限欄位只有 Manager，沒有可證實的站長／副站長
獨立角色欄位。上線驗收仍須由正式角色管理方核實兩者均有此正式授權；
測試中的兩個 Manager 身分不代表已核實正式帳號角色。

單元測試涵蓋本人、上傳者、兩個正式管理權限旗標、其他登入者、訪客、
Id=6 無權限負例、跨歌隔離與缺失身分。正式六身分與資料庫／Razor 整合驗收
須使用合法測試環境，不能以單元測試代替，也不得輸出正式私密正文。
