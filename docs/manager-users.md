# 使用者管理

`/Management/Users` 僅限資料庫 `Users.Manager = 1` 且未停用、未刪除的帳號。
桌面功能選單與手機功能列均顯示入口；一般使用者不輸出此入口。
清單每頁 25 筆，支援姓名、暱稱、Email、ID 搜尋與狀態篩選。
詳情提供原始帳號建立時間、UTC 最後登入時間、權限、狀態、可用活動統計、
App 登入方式與最近 50 筆管理紀錄。不提供密碼、token、provider subject、
IP 或私密留言內容。最後登入不代表在線，建立時間不推定時區。

部署前備份資料庫並執行 `docs/sql/008-manager-users.sql`；此為新增欄位與
操作紀錄表，不修改既有帳號狀態。舊網站使用新欄位不受影響，但新版需要此遷移。

所有異動僅接受防偽 POST；需輸入目標完整 Email、原因與讀取時的版本。
交易內重新驗證操作者的 Manager、目標狀態及版本，禁止操作自己與任何 Manager。
停用、啟用、軟刪除及 audit 一起提交，不接受過期表單或重複操作。
軟刪除保留帳號識別、歌曲與歷史，不能由此頁啟用，不是個資永久清除；
永久清除需另外檢閱既有帳號刪除、外部授權撤銷與關聯資料政策。

網站 session、持久 cookie、舊 App token、PKCE code 及新版 App bearer 都會在
下一次驗證時拒絕停用／刪除帳號。管理異動同時移除既有資料庫 App sessions。
不終止已開始的請求，也不宣稱登出所有外部 Google／Apple 工作階段。
