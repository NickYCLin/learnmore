# 參考錄音同步時間驗證

部分唱段無法取得可靠的語音辨識結果，但已有公開的同步歌詞。
`LearnMoreAPI/learnmore_api/reference_sources.json` 可登記指定歌曲、目標影片、
來源影片及 marumaru 歌曲頁，供既有 MCP 工作使用。登記內容只有公開來源資訊。

這條路徑核對的是「同一錄音上的來源同步時間」，不是逐字語音辨識命中。
未登記的歌曲仍使用 Demucs、Kotoba-Whisper 與 WhisperX。

接受條件：

- 來源頁仍使用登記的影片，歌詞行數、順序及每行文字與本站一致。
- 整段錄音相關係數至少 0.95，12 個 12 秒抽樣窗口各至少 0.90。
- 同一固定偏移涵蓋至少 95% 的錄音，沒有時間伸縮或逐行插值。
- 來源時間完整、有限、嚴格遞增，且落在來源與目標錄音範圍內。
- 網站重新核對影片、來源、抽樣數、分數、時長與覆蓋比例，不能僅憑來源名稱通過。

報告保留來源網址、兩個影片 ID、整段及窗口最低相關係數、偏移、覆蓋率與
來源時間表雜湊。仍需經過 MCP 預覽與套用，交易備份、原資料比對、讀回檢查均不變。
來源改版、文字不一致、下載失敗或錄音有剪接時，回到原音訊驗證，不標為完成。

來源時間本身可能有人工編排誤差；錄音比對只證明可使用同一時間軸，
不代表每行都有獨立的 ASR 命中。回報時必須明確區分兩種驗證方式。
